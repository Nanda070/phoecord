# What to read, and when

One index page for `docs/`. The working rules are in [`AGENTS.md`](AGENTS.md) (the single source of truth); this page only says where to go.

## Task → document

| What I am doing | What I read |
|:---|:---|
| Starting work | [`AGENTS.md`](AGENTS.md) (rules), [`CONTRIBUTING.md`](../CONTRIBUTING.md) (git and PR steps), then the plan's `AGENTS.md` if the work belongs to a plan |
| Changing code | [`CODE_MAP.md`](CODE_MAP.md) (which file does what), [`ARCHITECTURE.md`](ARCHITECTURE.md) (how the layers fit) |
| Which plugins we build, and which are done | [`PLUGINS.md`](PLUGINS.md): every Vencord plugin and userplugin, its layer and its task |
| Porting a plugin (Vencord, userplugin, new) | [`PORTING_PLUGINS.md`](PORTING_PLUGINS.md): step by step, with a worked example |
| Writing a plugin | [`ARCHITECTURE.md`](ARCHITECTURE.md) "Plugin API v1", the template in [`_template/code/`](_template/code/) |
| Working on Phase 1 | [`phase-1/README.md`](phase-1/README.md) (tasks and their status), [`phase-1/AGENTS.md`](phase-1/AGENTS.md) (for AI agents), [`phase-1/ai/`](phase-1/ai/) (spec, plan, ledger) |
| What is planned overall | [`ROADMAP.md`](ROADMAP.md) (stages; task status lives in the plan's README) |
| Something broke | [`RUNBOOK.md`](RUNBOOK.md) |
| Looking for a past decision | [`DECISIONS.md`](DECISIONS.md) (every `Ruling:` from the ledgers, by plan), [`CHANGELOG.md`](CHANGELOG.md) (what shipped and when) |
| Who owns what, access and secrets | [`GOVERNANCE.md`](GOVERNANCE.md) |
| Research notes | [`research/gpui.md`](research/gpui.md) (GPUI internals, stage 1.6); [`research/phoenix-desktop.md`](research/phoenix-desktop.md) (Desktop Phoenix and how a mod plugs in, task 2.1 prep) |
| Security | [`SECURITY.md`](../SECURITY.md) |

## Housekeeping

- [`_template/`](_template/): `ruling.md` (decision format) and code skeletons in `code/` (a native plugin with tests, a plugin manifest). Copy them, do not write from scratch.
- [`DECISIONS.md`](DECISIONS.md) is generated by `python scripts/gen_decisions.py`; never edit it by hand.

Checks before merging: `bash scripts/check.sh` (Windows: `powershell -File scripts/check.ps1`). CI also fails if `DECISIONS.md` is stale.
