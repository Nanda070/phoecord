# Website (phoecord.dev) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Astro static site in `site/` deployed to GitHub Pages at phoecord.dev (home, plugins, download; EN + RU), plus a refreshed README with the Discord link.

**Architecture:** Astro static output. Plugin data parsed at build time from `docs/PLUGINS.md` (+ `catalog/plugins.json`), release data from the GitHub API with a fallback. One layout, one i18n dictionary, page components shared by `/` and `/ru/`.

**Tech Stack:** Astro 7, TypeScript, plain CSS, Node test runner (`node --test`) for the parser.

**Spec:** `docs/superpowers/specs/2026-11-26-website-design.md`

## Global Constraints

- Discord invite: `https://discord.gg/cheterin`. Site: `https://phoecord.dev`. Repo: `https://github.com/Nanda070/phoecord`.
- Palette: #ff4d1a, #ff8a1f, #ffd24a accents; dark surfaces around #1e1f22 / #111214.
- No trackers, no external fonts/CDNs. No Vencord text or artwork copied.
- Docs, comments and commits in English; site copy in English and Russian.

## Review Focus

- A `PLUGINS.md` row with escaped pipes (`\|`) in the "Where" column must not split into extra cells.
- GitHub API unreachable or rate-limited at build: the build still succeeds and download buttons point to `releases/latest`.
- A release missing one OS's asset: that button falls back to `releases/latest`, others still link directly.
- Base path: the site runs at the domain root (`/`), so every internal link works on phoecord.dev and in `astro preview`.
- Plugin search with no matches shows an empty-state line, not a blank page.
