# Support

## For users

- Help with commands: `phoecord --help` (and the settings tab inside the client, once Phase 2 ships).
- A bug: open an issue with the [bug form](https://github.com/nanda070/phoecord/issues/new?template=bug_report.yml).
- An idea for a plugin: the [plugin form](https://github.com/nanda070/phoecord/issues/new?template=plugin_request.yml).
- Something broke after a Discord update: check [`RUNBOOK.md`](RUNBOOK.md) first.
