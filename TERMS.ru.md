# Условия использования PhoeCord

Версия: 1

Прочитайте это перед установкой PhoeCord. Текст короткий. Принять его нужно один раз; если условия изменятся, вас спросят снова.

## 1. Что такое PhoeCord

PhoeCord — неофициальная модификация клиента Discord с открытым исходным кодом. Он **не связан с Discord Inc., не одобрен и не поддерживается ею**. «Discord» — товарный знак его владельца.

## 2. Это нарушает правила Discord, ваш аккаунт под риском

Модификация клиента Discord противоречит Условиям использования Discord. Discord может ограничить, заблокировать или забанить аккаунт, который использует модификацию клиента. **Этот риск вы принимаете на себя.** Плагины, которые выполняют много действий сразу (массовое удаление, рассылка, массовое вступление и т. п.), повышают его. Команда PhoeCord не может восстановить забаненный аккаунт.

## 3. Без гарантий и без ответственности

PhoeCord предоставляется «как есть». Разработчики не отвечают за любой ущерб от его использования. Точная формулировка — в разделах 15 и 16 лицензии GPL-3.0-or-later в файле [`LICENSE`](LICENSE).

## 4. Что PhoeCord делает на вашем компьютере

- Создаёт **локальный удостоверяющий центр (CA)**, который существует только на вашем компьютере. Он может подписывать сертификаты только для `discord.com`, `discordapp.com`, `discord.gg` и их поддоменов.
- **Добавляет этот CA в хранилище доверенных сертификатов.**
- Запускает **локальный прокси на `127.0.0.1`**, который читает трафик Discord API и Gateway только на этом компьютере. Остальной трафик проходит без изменений.
- Может **запускаться при входе в систему**, если вы это оставите включённым.
- **Телеметрии нет.** Ничего не отправляется ни разработчикам, ни кому-либо ещё.

Чтобы убрать всё это, выполните `phoecord uninstall`. Команда отменяет всё, что сделал `phoecord setup`.

## 5. Плагины от других людей

Установка стороннего плагина — ваш выбор и ваша ответственность. WASM-плагины работают в песочнице и имеют только те права, которые они показывают. Нативные плагины работают с полными правами на вашем компьютере: ставьте их только из источников, которым доверяете.

## 6. Релизы без подписи

Релизы не подписаны цифровой подписью, поэтому система может выдать предупреждение при запуске. Сверьте файл с `SHA256SUMS` на странице релиза.

## 8. Изменения

Условия могут меняться. У каждой версии есть номер. Когда номер растёт, PhoeCord снова показывает условия, и их нужно принять заново.
